# Alzheimer's Detection from MRI Scans

A deep learning application that analyzes brain MRI scans to detect signs of Alzheimer's disease.

## Model Information
- **Input**: Brain MRI Image (128x128 pixels)
- **Output**: Classification into 4 categories:
  - Non-Demented
  - Very Mild Demented  
  - Mild Demented
  - Moderate Demented

## How to Use
1. Upload an MRI brain scan image
2. Fill in patient information (optional)
3. Click "Analyze MRI"
4. View the diagnosis and recommendations

## Technology Stack
- TensorFlow/Keras CNN Model
- Gradio Interface
- Google Gemini AI for report generation
